# apps/mobile

Expo SDK 58(Expo Router) 앱. Expo Go로 연다(아이폰 실기기 제외, 루트 README 참고).

- 실행·검사 명령: 루트 [`CLAUDE.md`](../../CLAUDE.md) 명령표. 화면 확인은 `pnpm --filter mobile exec expo start --web`
- 시세 API 주소: `EXPO_PUBLIC_API_BASE_URL`(기본값은 배포된 웹)
- Expo API는 SDK마다 바뀐다. [`AGENTS.md`](AGENTS.md)대로 버전 문서를 먼저 확인한다
