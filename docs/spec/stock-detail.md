# 종목 상세

- 상태: 확정
- 관련 이슈: #10, #15, #16 (spec 작성 #6)

## 1. 목적
한 종목의 현재가, 오늘 등락, 기간별 가격 흐름을 차트 하나로 본다. 이 화면이 앱과 웹을 나란히 띄웠을 때 같은 값이 같이 움직이는 장면의 주인공이다.

## 2. 화면
| 플랫폼 | 화면 | 구성 |
|---|---|---|
| 웹 넓은 화면(60rem 이상) | `/stocks/{ticker}` | 왼쪽 관심 종목 표(`watchlist.md`) + 오른쪽 상세 |
| 웹 넓은 화면 | `/` | 오른쪽은 빈 상태: "왼쪽에서 종목을 고르세요" |
| 웹 좁은 화면 | `/stocks/{ticker}` | 상세만. 위에 "관심 종목"으로 돌아가는 링크 |
| 앱 | 상세 화면(Expo Router 동적 경로) | 상세만. 스택 헤더의 뒤로 가기 |

### 상세 구성 (위에서 아래로)
1. 티커(Plex Mono 500)와 종목명(`muted`)
2. **현재가**: 이 화면의 주인공. Plex Mono 500, 화면에서 가장 큰 글자(웹 56px 안팎, 앱 40px 안팎), `tabular-nums`
3. 등락과 등락률(`+1.86 +0.81%`, 상승 `up`/하락 `down`)과 "오늘 0시 대비"
4. 기간 선택: 1시간, 1일, 1주, 1개월. 붙어 있는 버튼 묶음, 선택된 것은 테두리 `ink`
5. **차트**: 선 하나
6. 수치: 기준가, 고가, 저가(라벨 Newsreader `muted`, 값 Plex Mono). 표 머리처럼 위에 2px `rule-2`

### 차트 규칙
- 선 2px. 색은 마지막 값이 기준가보다 높으면 `up`, 낮으면 `down`
- 기준가가 차트 범위 안에 있으면 1px `rule-2` 가로선과 "기준가 231.42" 라벨을 긋는다. 범위 밖이면 긋지 않는다(1시간 차트는 대부분 범위 밖이다). 기준가 값은 수치 칸에 항상 있다
- 가로 격자 3~5개(1px `rule`, 실선). y축 값은 오른쪽에 Plex Mono, x축 시각은 아래에
- 마지막 점에 지름 6px 점 하나. 그 밖의 표식, 그림자, 채우기, 그라데이션 없음
- y축은 데이터 범위에 맞춘다(0부터 시작하지 않는다). 축 값을 항상 보여 주어 확대된 범위임을 알 수 있게 한다
- 차트에는 대체 텍스트를 붙인다: "AAPL 최근 1시간, 229.80에서 231.42, 고가 232.10, 저가 228.95"

## 3. 데이터
- `useQuote(ticker)`(목록과 같은 요청을 함께 쓴다)로 현재가·등락·기준가·고가·저가, `useHistory(ticker, range)`로 차트 점. 정의는 `market-data.md`
- 선택한 기간은 주소에 둔다: 웹 `?range=1d`, 앱 경로 파라미터. 새로고침하거나 링크를 공유해도 같은 기간이 열린다. 기본값은 1시간

## 4. 동작 규칙
| 상태 | 웹 | 앱 |
|---|---|---|
| 로딩(처음) | 현재가 자리와 차트 자리가 실제 크기의 뼈대로 잡혀 있다 | 같음 |
| 기간 전환 중 | 이전 차트를 흐리게 두고 새 이력을 받는다. 빈 화면으로 깜빡이지 않는다 | 같음 |
| 빈 값 | 해당 없음 | 같음 |
| 없는 티커 | 404 페이지: "목록에 없는 종목입니다"와 관심 종목 링크 | "목록에 없는 종목입니다"와 뒤로 가기 |
| 오류(값이 아직 없음) | "시세를 불러오지 못했습니다"와 "다시 시도" | 같음. 오프라인이면 "오프라인입니다"(오류가 아니라 `fetchStatus: "paused"`로 판정) |
| 오류(값이 있었음) | 마지막 값과 차트를 유지하고 "N초 전 시세" 표시 | 같음 |
| 값 갱신 | 현재가·등락 숫자만 바뀐다. 1시간 차트는 마지막 점이 이어진다. 깜빡임 없음 | 같음 |
| 장 마감 시간 | 해당 없음(24시간 시뮬레이션) | 같음 |

- 웹 넓은 화면에서 종목을 바꾸면 주소가 `/stocks/{ticker}`로 바뀌고, 뒤로 가기로 이전 종목에 돌아간다
- 기간 버튼은 키보드로 고를 수 있고, 선택 상태를 보조 기술에 알린다(`aria-pressed` 또는 그에 맞는 RN 접근성 속성)

## 5. 수용 기준
앱 화면은 Expo 웹 미리보기(`expo start --web`)로 배치·색·차트를 확인한다. **(기기)** 표시 기준은 브라우저로 판정할 수 없는 네이티브 동작이라, 안드로이드 기기를 쓸 수 있을 때 #4와 함께 몰아서 확인한다(지원자 결정).

- [ ] 웹 `/stocks/AAPL`과 앱 AAPL 상세(웹 미리보기)가 같은 시각에 같은 현재가를 보여 주고 1초마다 함께 바뀐다
- [ ] **(기기)** 같은 장면을 안드로이드 Expo Go와 웹으로 나란히 확인한다(README 영상의 재료)
- [ ] 현재가가 화면에서 가장 큰 글자이고, 등락 색이 기준가 대비 방향과 맞다
- [ ] 1시간·1일·1주·1개월 차트가 §2 차트 규칙대로 그려진다(격자 3~5개, 범위 안일 때 기준가 선, 오른쪽 y축, 마지막 점)
- [ ] 기간이 주소에 남아 새로고침 후에도 유지된다(웹 `?range=`)
- [ ] 기간을 바꿀 때 차트 자리가 비지 않는다
- [ ] 없는 티커에서 웹은 404, 앱은 안내 화면이 나온다
- [ ] 오류(값 없음/값 있음) 두 경우가 §4대로 보인다
- [ ] 웹 넓은 화면에서 목록과 상세가 함께 보이고, 60rem 미만에서는 상세만 보인다. 375px에서 넘치는 요소가 없다
- [ ] 차트 웹·앱 렌더링이 `packages/`의 같은 좌표 함수를 쓴다
- [ ] 웹 `/stocks/AAPL`이 Hallmark `sloplint --scope app` FAIL 0이다

## 7. 결정 기록
- **차트 라이브러리 없이 SVG를 직접**(설계자 판단): 웹과 앱이 좌표 계산을 공유하고 그리기만 따로 한다. 라이브러리를 쓰면 플랫폼마다 다른 라이브러리가 필요해 같은 차트가 다르게 생긴다. 필요한 표현(선, 격자, 기준선, 점)이 적어 직접 그리는 편이 작다
- **선 색을 기준가 대비 방향으로**(설계자 판단): 이 앱에서 색은 상승·하락만 뜻한다는 규칙을 차트에도 적용한다
- **기간을 주소에**(설계자 판단): 공유와 새로고침에서 같은 화면이 열려야 한다(Hallmark 앱 화면 기준 "상태는 URL에")
- **툴팁·십자선 없음**(설계자 판단): 1주 범위에서 필요한 상호작용이 아니다. 차트는 흐름을 보여 주고, 정확한 값은 현재가와 수치 칸이 맡는다
